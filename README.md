# Ma config Helix

Vous retrouverez dans le dossier `helix/` le `config.toml` et le `languages.toml`.

Ma config est actuellement préparée uniquement pour du Python et du C/C++.

Helix a besoin d'autres outils pour des fonctionnalités supplémentaires comme l'autocomplétion. `install.sh` s'en occupe.
